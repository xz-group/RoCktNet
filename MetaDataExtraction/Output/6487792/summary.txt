# An 8Gb/s 0.65mW/Gb/s Forwarded-Clock Receiver Using an ILO with Dual Feedback Loop and Quadrature Injection Scheme Ji-Hwan Seol1, Young-Ju Kim1, Sang-Hye Chung1, Kyoung-Soo Ha2, Seung-Jun Bae2, Jung-Bae Lee2, Joo Sun Choi2, Lee-Sup Kim1

FIGURE NUMBER
"Figure 23.6.1 shows a block diagram of our receiver. It consists of the ILO and data samplers. 1:4 demultiplexing is used to alleviate the operating speed of the ILO and data samplers. The ILO generates quadrature clocks for the data samplers and performs deskew. The ILO is composed of a main ILO, input mixer and quadrature injector, which are made of identical delay cells. The main ILO is a 2stage ring oscillator with an injection port at each delay cell. The injection clock for the main ILO’s first delay cell comes from the input mixer, which is used to reduce the required frequency tuning range for deskew. The input mixer also provides the input clock for the quadrature injector. The output clock of the quadrature injector is injected to the second delay cell of the main ILO for the generation of accurate multiphase clocks."
